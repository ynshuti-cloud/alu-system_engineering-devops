# web_server

Nginx web server project (alu-system_engineering-devops).

| File | Purpose |
|------|---------|
| `0-transfer_file` | Copies a file to a server's `~/` with scp |
| `1-install_nginx_web_server` | Installs nginx, serves "Holberton School" on port 80 |
| `2-setup_a_domain_name` | Domain name pointing to web-01 |
| `3-redirection` | Adds a 301 redirect on `/redirect_me` |
| `4-not_found_page_404` | Custom 404 page ("Ceci n'est pas une page") |
| `5-design_a_beautiful_404_page.html` | Styled 404 page |
